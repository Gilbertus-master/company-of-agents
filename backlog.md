# Organisation backlog

Kept by the PM agent (`role/pm.md`). This is an index with links, not a copy of the orders. Every one-off order and every recurring task has
a row here with an owner, a deadline and a status. Every Friday the PM assesses whether recurring tasks are justified (cost versus value;
`pm/szablony/przeglad-cyklicznych.md`) and submits proposals to the CEO.

Priority: **P1** legal deadline / production / revenue · **P2** weekly plan (`Plan:` in the order) · **P3** the rest.
Status (written in Polish, as the tool reads it): otwarte (open) / w toku (kto) (in progress, who) / czeka: kto (waiting: who) /
zrobione (data) (done, date) / odłożone (deferred) / informacja (information). `PO TERMINIE (+N d)` (overdue) in the „Uwaga PM” column
= the deadline has passed and there is no answer. Deadline `(dom.)` = an order without a `Termin:` line (default 12 h from the entry);
`– (tekst)` = a deadline dependent on an event (e.g. "after decision no. N") – it does not count as overdue, but it must have an owner.

**The „Jednorazowe” (one-off) section is generated by** `python3 -I pm/narzedzia/backlog.py` from the inboxes `zlecenia/*.md` and Issues
`typ:zlecenie` (row key: `Z-RRRRMMDD-NN`, Issue `#N`, or file + subject). The columns **Właściciel, Temat, Źródło, Termin, Status**
(owner, subject, source, deadline, status) are overwritten by the tool; **Id, P, Plan, Uwaga PM** (PM note) are manual (the PM enters EV
and cost for P1–P2) – the tool keeps them and only adds its own markers
(`PO TERMINIE`, `brak linii Termin:`, `odpowiedź jest – nagłówek otwarty (M-03)`, `status md ≠ Issue`, `źródło zniknęło`).
`python3 -I pm/narzedzia/backlog.py --sprawdz` lists overdue items, duplicates and tasks from `flota/zadania.yaml` without a C row.
