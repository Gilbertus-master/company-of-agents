# Security – shared files

- `audyt/RRRR-MM.jsonl` – a record of EVERY permissions-hook decision (pre: allow/deny, post: executed) with a SHA-256 chain (`prev_hash` → `hash`); retention ≥ 6 months (AI Act Art. 26 – an obligation for deployers of high-risk systems; good practice for others), `merge=union`.
- `blokady.jsonl` – denials only (a shortcut for the weekly review: the CEO uses it to decide on loosening `uprawnienia.yaml`).
- `HALT` – kill switch: while the file exists, the hook stops every agent session at the first tool call other than a read. Created by the watchdog (fleet budget ≥ 100 %) or by a human; removed by the operator after review.
- `skan-danych-wyjatki.tsv` – exceptions for the personal-data scanner `scripts/skan-danych.py` (group `skan danych` in `scripts/testy.sh`; `--staged` as a pre-commit hook): file, category, SHA-256 of the value (never the value itself), reason; `merge=union`.
- `rejestry-wrazliwe.tsv` – registers whose real entries live outside the repo: git (files and history) holds only headers and rows without data; checked by `scripts/rejestry-git.py` (group in `scripts/testy.sh`, output without row contents). A company-local list.
- `zasady-skroty.json` – SHA-256 hashes of section A of `zasady.md` and of the block `flota/szablony/bloki/zasady-bezpieczenstwa.md` (with the number of the decision that set them; `start` = shipped with the template) and exceptions for task texts without the block (with a reason). `python3 -I scripts/zasady_skroty.py sprawdz` (group `zasady` in `scripts/testy.sh` and a separate CI step): rules changed, removed or cut out of a task text or prompt = red CI = the PR will not pass the merge queue. A deliberate change: in the same PR, `aktualizuj --decyzja D-RRRRMMDD-NN` (the decision file must exist); removing a source – only explicitly with `--usun <klucz>`.
