# For the owner's decision – one list

Kept by the CEO agent. Only matters not settled by `decyzje.md`, `zasady.md`, `uprawnienia.yaml` or the agent's
scope. Most important at the top. Every matter has a recommendation and the consequence of delay – the owner answers "yes / no /
otherwise: …". After the decision: a `D-…` entry in `decyzje.md`, the item removed from here, orders to the agents.

**One place.** No owner decision exists outside this list: a question to the owner in a report, order, PR description,
email or chat without a row here is an error (check A-12). An agent that needs the owner's decision writes to the CEO;
the CEO first checks whether it may decide itself (`uprawnienia.yaml`, `decyzje.md`) and if not, adds the row in the same
run. If the owner prefers a page with buttons to a file (e.g. a private Artifact page with an answers database), this list
stays the source and the page is its mirror: in every run the CEO reads the answers from the page, carries them here and
into `decyzje.md`, and adds every new row to the page as well.

The default answer after the deadline passes is **"no"** (the safe option) – the CEO plans so that a missing answer
does not block the organisation.
